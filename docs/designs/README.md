# EGM Design Specifications Directory

This directory stores living technical specifications created using the **Elephant-Goldfish Model (EGM)** plugin.

For the full catalog of design specifications, workflow lifecycle, and Monika architectural constraints, see **[SITEMAP.md](SITEMAP.md)**.

### Quick Commands (Antigravity):
- `/egm-brainstorm <feature idea>` — Explore problem boundaries and draft `concepts_brief.md`.
- `/egm-draft` — Draft specification section-by-section into this directory.
- `/egm-review docs/designs/<feature>.md` — Execute zero-context multi-stage Goldfish review.
- `/egm-resolve` — Triage review findings and update specifications.
- `/egm-drift-report docs/designs/` — Compare code against design documents.
