# Walk-Forward Optimization & Alpha Validation Playbook

## 1. Mathematical Architecture & Invariants
Implements rolling out-of-sample alpha verification in `backtest/walk_forward_engine.py` and statistical significance testing in `backtest/statistical_tests.py`.

### 1.1 Walk-Forward Efficiency (WFE)
$$WFE = \frac{\text{Mean Annualized Sharpe}_{\text{Out-of-Sample}}}{\text{Mean Annualized Sharpe}_{\text{In-Sample}}}$$
- **Institutional Standard**: $WFE \ge 0.60$ (minimum 60% of in-sample alpha retained out-of-sample).
- **Overfitting Rejection**: $WFE < 0.50$ triggers disqualification of the candidate strategy.

### 1.2 Purged & Embargoed Cross-Validation (de Prado Method)
- **Purging**: Remove training labels whose returns span across test fold entry boundaries to eliminate lookahead bias.
- **Embargoing**: Discard $2.0\%$ of observations immediately following test fold exits to extinguish autoregressive serial correlation.

### 1.3 Deflated Sharpe Ratio (DSR) & Probabilistic Sharpe Ratio (PSR)
$$DSR = \Phi\left(\frac{(SR - SR^*)\sqrt{T-1}}{\sqrt{1 - \gamma_3 SR + \frac{\gamma_4 - 1}{4} SR^2}}\right)$$
- **Acceptance Gate**: $DSR \ge 0.55$ across multiple trials. Rejects false alpha generated by trial multiplicity.

## 2. Standard Walk-Forward Evaluation Grid
| Metric / Parameter | Mandatory Threshold | Rationale |
|:---|:---|:---|
| **In-Sample Lookback** | $90\text{--}180\text{ days}$ | Captures structural macro regime transitions. |
| **Out-of-Sample Window** | $30\text{ days}$ | Mimics real monthly adaptive recalibration. |
| **Minimum Folds** | $\ge 4\text{ temporal folds}$ | Verifies cross-seasonal robustness. |
| **Minimum OOS Trades** | $\ge 15\text{ trades per fold}$ | Guarantees statistical significance. |
| **DSR Minimum Gate** | $\ge 0.55$ | Rejects spurious curve-fitting. |
